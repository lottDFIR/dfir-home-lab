# DFIR Home Lab & Case Studies

Self-directed learning log as I build toward a Digital Forensics / Incident Response role. 
Documenting my home lab setup, tools, and hands-on case investigations as I go — no prior 
industry experience, starting from the ground up.

## Setup
- SIFT Workstation (SANS) running on Ubuntu 22.04 LTS, virtualized in UTM on Apple Silicon

## Structure
- /cases — writeups of individual forensic investigations using public sample images
- /notes — artifact reference notes as I learn them (registry, event logs, etc.)
- /tools — any scripts I write along the way
